# Gõ tay phải

Web luyện gõ phím bằng **một tay phải** (Tiếng Việt + English), theo kiểu 10FastFingers.
Web tĩnh, không cần tài khoản; kết quả lưu trong trình duyệt.

## Chạy trên máy

Cần Node.js 22 trở lên.

```bash
npm install
npm run dev      # mở http://localhost:5173
```

## Lệnh khác

```bash
npm test         # unit test (Vitest)
npm run lint     # ESLint + Prettier
npm run build    # bản production vào dist/
npm run wordlists  # tạo lại danh sách từ (tải dữ liệu FrequencyWords)
```

Kế hoạch: `PLAN.md`. Nguồn danh sách từ: `ATTRIBUTION.md`.
